# 00 — Master PRD

## 1. 產品名稱

暫定：**TW Market Ledger**

## 2. 產品願景

建立一個以台灣股票投資人為核心的 Android App，將大盤現貨、台指期貨、法人現貨與期貨部位、融資融券、借券、產業族群、個股技術面、持股成本及提醒整合在同一套介面。

## 3. 核心使用者問題

App 首頁與持股頁應能快速回答：

- 今天加權指數與櫃買指數強不強？
- 台指期貨比現貨強或弱？
- 期貨是正價差或逆價差？
- 外資、投信、自營商現貨在買或賣？
- 三大法人台指期未平倉是加多、加空或回補？
- 大盤融資、融券及借券是否擴張？
- 哪些產業或題材正在轉強？
- 我的持股目前損益與均線位置如何？
- 哪些持股、自選股或大盤條件剛被觸發？

## 4. 功能範圍總表

### 4.1 市場總覽

- 加權指數與櫃買指數。
- 開、高、低、收／最新價、漲跌點、漲跌幅。
- 成交金額、上漲／下跌／平盤家數、漲跌停家數。
- MA5、MA10、MA20、MA60、MA120、MA240。
- RSI、KD、MACD、成交量均線。
- 距離重要均線百分比。
- 台股波動率指標。
- 現貨法人買賣超。
- 全市場融資、融券、借券。
- 資料最後更新時間及是否為盤中、盤後、延遲或最終資料。

### 4.2 台指期貨與衍生品

- 近月台指期即時／延遲行情。
- 開、高、低、最新價、漲跌、成交量、未平倉量。
- 期現貨價差與正／逆價差。
- 契約到期日、結算剩餘日。
- 台指期連續月歷史圖。
- 小型台指、微型台指、電子期、金融期。
- 夜盤狀態。
- 近月與次月價差。
- 外資、投信、自營商期貨多方／空方／淨部位。
- 三大法人未平倉口數、契約金額與每日變化。
- 前五大／前十大交易人未平倉集中度。
- Put／Call Ratio。
- 最大買權與賣權未平倉履約價。
- 最大痛點估算；標示為衍生計算值。
- 台指選擇權波動率指標。

### 4.3 法人與信用交易

大盤及個股皆支援：

- 外資買進、賣出、買賣超。
- 投信買進、賣出、買賣超。
- 自營商自行買賣。
- 自營商避險。
- 自營商合計。
- 三大法人合計。
- 當日、5日、10日、20日、60日及自訂區間累計。
- 融資買進、賣出、現償、餘額、增減、使用率。
- 融券買進、賣出、券償、餘額、增減、使用率。
- 券資比。
- 借券賣出、還券、餘額、每日及區間變化。
- 價格與籌碼疊圖。

### 4.4 個股搜尋與分析

搜尋：

- 代號。
- 公司名稱。
- 模糊名稱。
- 產業。
- 題材。

圖表期間：

- 1日。
- 5日。
- 10日。
- 30日。
- 1年。
- 5年。

圖表：

- 分時線。
- K 線。
- 成交量。
- 十字游標。
- 縮放與平移。
- 原始／還原權息切換。

技術指標：

- MA、EMA。
- Bollinger Bands。
- MACD。
- RSI。
- KD。
- OBV。
- ATR。
- Williams %R。
- 成交量均線。
- 前高、前低及使用者支撐壓力線。

### 4.5 產業與題材

官方產業：

- 半導體、電子零組件、電腦週邊、通信網路、光電、金融、航運、生技、鋼鐵、汽車等。

自訂題材：

- DRAM、NAND、HBM、PCB、CCL、AI 伺服器、CPO、矽光子、機器人、散熱、重電、軍工、低軌衛星、被動元件等。

每個分類顯示：

- 等權平均漲跌幅。
- 市值加權漲跌幅。
- 成交金額與市場占比。
- 上漲、下跌、漲停、跌停家數。
- 站上月線與季線比例。
- 法人買賣超。
- 融資、融券、借券變化。
- 產業強度排名。
- 3 至 10 家指標公司。
- 領漲、領跌公司。
- 產業熱度歷史。

### 4.6 投資組合

使用者唯一需要輸入的交易欄位：

- 股票代號。
- 買進／賣出。
- 日期與時間。
- 股數。
- 成交價格。
- 手續費。
- 零股／整股。

系統計算：

- 持有股數。
- 平均成本。
- 總投入金額。
- 已實現損益。
- 未實現損益。
- 目前市值。
- 總損益。
- 報酬率。
- 個股與產業配置比例。
- 每日部位快照。
- 損益貢獻度。

限制：

- MVP 使用移動平均成本法。
- 不建立公司事件、股利、除權息、減資及增資輸入。
- 不允許賣出超過可用持股。
- 整股與零股統一以「股」計算。

### 4.7 持股與均線提醒

每日更新：

- MA5、MA10、MA20、MA60、MA120、MA240。

支援：

- 接近均線。
- 盤中碰觸。
- 向上突破。
- 向下跌破。
- 收盤站上。
- 收盤跌破。
- 連續 N 日站上／跌破。
- 使用者自訂距離百分比。
- 通知冷卻與每日上限。

提醒範圍：

- 大盤。
- 台指期貨。
- 持股。
- 自選股。
- 法人。
- 融資融券與借券。
- 期貨未平倉。
- 成交量與技術指標。
- 產業強度。

### 4.8 自選股

- 多群組。
- 新增、刪除、拖曳排序。
- 同一股票可屬於多群組。
- 備註。
- 目標價、停損價、加碼價。
- 自訂提醒。
- 欄位排序。
- CSV 匯入／匯出，列為進階功能。

### 4.9 市場多空儀表板

整合：

- 現貨指數。
- 台指期。
- 期現貨價差。
- 三大法人現貨。
- 三大法人期貨未平倉。
- 融資、融券、借券。
- Put／Call Ratio。
- VIX。
- 成交量。
- 市場廣度。
- 大盤與均線距離。

以客觀卡片呈現，不輸出買賣結論。

### 4.10 背離與狀態辨識

規則包括：

- 外資買超但價格下跌。
- 外資賣超但價格上漲。
- 融資增加且價格下跌。
- 融資下降且價格上漲。
- 借券增加且跌破月線。
- 投信連買但成交量縮小。
- 法人現貨買超但期貨加空。
- 法人現貨賣超但期貨空單回補。
- 未平倉增加且期貨下跌。
- 產業上漲但多數成分股下跌。

輸出需包含命中條件與原始數值。

條件可自由組合：

- 股價與均線關係。

- 突破近期高低點。
- 量能放大。
- RSI、KD、MACD。
- 產業強度排名。
- 距離均線百分比。
- 市值、價格、成交金額。
- 題材與產業。

支援儲存篩選條件與每日通知。

## 5. 明確排除

- 下單與券商交易。
- 自動交易。
- 保證獲利或買賣推薦。
- 投資組合公司事件輸入。
- 未授權即時行情重散布。
- 使用不穩定網頁爬蟲作為正式資料來源。

## 6. 非功能需求

### 效能

- 首頁快取資料 1 秒內顯示。
- 一般 REST API P95 小於 500 ms；大型圖表查詢另設上限。
- 分鐘 K 線採分頁或時間窗查詢。
- WebSocket 僅推送已訂閱商品。
- Room 支援離線快取。

### 可用性

- API 顯示 `as_of`、`received_at`、`data_status`。
- 資料延遲需顯眼標示。
- 上游失敗時呈現最近成功資料與 stale 狀態。
- 排程可重跑且具冪等性。

### 安全

- JWT／OAuth2。
- Android token 儲存於加密儲存。
- 生物辨識可鎖住投資組合畫面。
- API Rate Limit。
- 不在日誌紀錄完整 token 或敏感個人資料。

### 可觀測性

- 結構化日誌。
- Job 執行紀錄。
- 上游資料筆數與校驗結果。
- API latency、error rate。
- 告警規則觸發與推播成功率。

## 7. 成功指標

- 使用者能在 10 秒內確認大盤現貨、期貨與外資方向。
- 使用者能在 30 秒內新增一筆交易。
- 持股部位與損益計算無誤。
- 盤後資料於預定時間內完成更新。
- 規則觸發不重複轟炸。
- 每筆市場資訊皆可辨認資料日期、來源與狀態。
